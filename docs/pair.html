  1. Откройте приложение на телефоне
  2. Настройки → Сканировать QR
  3. Наведите камеру на код слева

Автоматический вход выполняет расширение Tampermonkey со скриптом. Без него роутер откроется, но пароль придётся ввести вручную.

Наведите камеру телефона на код

Как это работает

  1. Код показывает компьютер, а читает телефон.
  2. Телефон шифрует данные роутера и передаёт их на компьютер.
  3. Компьютер расшифровывает и входит в роутер сам.

Код показывает компьютер, потому что страница роутера открывается по обычному http:// — браузер не даёт такой странице доступ к камере. Камера есть только у телефона.

Данные зашифрованы ключом из самого кода. Ключ есть только у этих двух устройств, поэтому посредник видит нечитаемый набор байт, и тот не сохраняется. Вход выполняет расширение Tampermonkey со скриптом — скачать его можно кнопкой ниже.
